Master Plan & Framework

How This System Works

This is a spiral-review assessment system built directly from Taʿlīm al-Ṣibyān al-Tawḥīd (Shaykh Muḥammad ibn ʿAbd al-Wahhāb) and cross-checked against both AMAN slide decks. It assumes roughly 30 weekend sessions across the school year — adjust week numbers to your actual calendar (holidays, breaks, etc.).

Every new concept is introduced once, then deliberately revisited in every review week and every cumulative quiz/exam after it — nothing is assessed only once and then dropped. Four quizzes, one midterm, and one final are spaced through the year, each preceded by a dedicated review session (see the pacing table below).

Companion document This document is the framework. A fully worked example — Unit 1's complete packet, with every activity type and a full answer key — is provided separately so you can see exactly how the system is meant to be used. Ask and I will build out each remaining unit in this same format.

Grading Scale

Recommended for elementary Islamic studies — mastery-based rather than punitive, since the goal is retention, not ranking:

  • 90–100% — Mastered (Mumtāz / أَحْسَنْت) — ready to move on, can help as a peer tutor
  • 75–89% — Proficient (Jayyid Jiddan) — solid, revisit only the missed items
  • 60–74% — Developing (Jayyid) — needs a re-teach of specific items before moving on
  • Below 60% — Needs Support (Yaḥtāj Musāʿadah) — reteach 1-on-1 or in a small group before the next quiz

For younger Level 1 students, consider reporting mastery only (✓ Mastered / ● Practicing / — Not Yet) instead of a percentage — see the Student Scoring Sheet template in each unit packet.

Suggested Point Values

  • Multiple choice / True–False: 1 point each
  • Fill-in-the-blank: 2 points each (1 for correct meaning, 1 for correct Arabic spelling, if applicable)
  • Matching: 1 point per correct pair
  • Short answer (1–2 sentences): 3 points (content 2, completeness/clarity 1)
  • Complete-sentence Q&A recitation (Arabic, from memory): 5 points — see Oral Recitation Rubric
  • Short written response / reasoning question: 4 points — see Written Assignment Rubric
  • Exit tickets: ungraded, or 1 point completion credit — formative, not evaluative
  • Homework: completion credit (1–2 pts) unless otherwise noted in a specific packet

Year-Long Pacing Guide

AMAN's real calendar runs June–December, meeting both Saturday and Sunday each weekend — 60 sessions total (June 8 · July 8 · Aug 10 · Sep 8 · Oct 9 · Nov 9 · Dec 8). This plan uses 30 weekend blocks of 2 sessions each (Sat + Sun = the "Day 1 / Day 2" split inside every unit packet), which maps onto the real calendar exactly: Weekend 1 = Sessions 1–2, Weekend 2 = Sessions 3–4, and so on through Weekend 30 = Sessions 59–60. "New" weekends introduce content; "Review" weekends are cumulative and spiral back through everything taught so far — never only the most recent unit.
