How to get your files into the hub

Tap Import Files and multi-select everything from your phone at once — the hub matches each one to its card by file name and remembers it from then on, right inside Claude. Tap any card afterward and it opens the real file in a viewer on this page, no new tab, no dead link.

Prefer one at a time, or need to replace a single file? Use the small Upload button on that card. The Setup Checklist above shows which ON DEVICE files still need uploading.

Two honest limits: the built-in upload only works while you're using this hub inside Claude — if you save this file and open it directly in your phone's browser instead, put your files in a files folder next to it and the same cards will open them from there. And Excel/PowerPoint files (.xlsx, .pptx) can't be previewed inline — the viewer gives you a direct download for those instead.
