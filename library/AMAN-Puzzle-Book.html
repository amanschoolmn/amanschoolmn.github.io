How to Solve Each Puzzle Type
Read this first!
GUIDE

🔍 Word Search — find every word from the list hidden in the grid. Words can run left-right, right-left, up-down, down-up, or diagonally.

🧩 Crossword — use the Across and Down clues to fill in the grid. Numbers on the grid match the clue numbers.

🔢 Word Scramble — unscramble the jumbled letters to spell the correct word. The clue tells you what to look for.

🔗 Matching — draw a line (or write the letter) connecting each term on the left to its correct meaning on the right.

🔑 Decode It (Cryptogram) — every letter in the secret message has been swapped for a number. A few letters are given free to get you started. The same number always means the same letter!

🪝 Knowledge Ladder — climb the ladder! Each answer is exactly one letter longer than the answer before it. Use the clues to fill every box, shortest word first.

⭐ Acrostic — every answer starts with the gold letter shown. Solve them all and read the gold letters top to bottom to reveal a hidden word!
